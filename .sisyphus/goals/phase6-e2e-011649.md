## 验证标准

### 功能验证

1. **净值增长率抽取**（6A）
   - 2021-2025 年净值增长率数据非空
   - 列头截断（"份额净值增长"）能正确匹配

2. **基金经理/规模接入**（6B）
   - Ch1 包含基金经理姓名和任职日期
   - Ch5 包含期末净资产和份额数据

3. **preferred_lens 适配**（6C）
   - 根据 fund_type 自动选择对应的 preferred_lens
   - LLM prompt 包含"优先回答什么"指引
   - 数据缺失时使用降级声明

4. **评分框架感知**（6D）
   - 主动基金：6 指标 135→100 归一化
   - 被动基金：3 指标 100 分制（费率40+规模30+持仓30）
   - 债券基金：5 指标（超额收益+费率+规模+经理+持仓）

### 端到端验证

```bash
# 1. 导入 5 年年报
uv run fund-checklist import 基金年报/011649_易方达逆向投资混合_2021_annual_report.pdf
uv run fund-checklist import 基金年报/011649_易方达逆向投资混合_2022_annual_report.pdf
uv run fund-checklist import 基金年报/011649_易方达逆向投资混合_2023_annual_report.pdf
uv run fund-checklist import 基金年报/011649_易方达逆向投资混合_2024_annual_report.pdf
uv run fund-checklist import 基金年报/011649_易方达逆向投资混合_2025_annual_report.pdf

# 2. 多年度聚合
uv run fund-checklist multi-year --fund-code 011649 --years 2021,2022,2023,2024,2025

# 3. 生成报告（LLM 接入）
uv run fund-checklist generate --fund-code 011649 --fund-name "易方达逆向投资混合A" --year 2025 --work-dir .fund_checklist_e2e_011649

# 4. 三层审计
uv run fund-checklist audit --fund-code 011649 --year 2025
uv run fund-checklist deep-audit --fund-code 011649 --year 2025

# 5. 检查报告质量
cat 基金年报/report/011649_易方达逆向投资混合A_2025_analysis.md
```
