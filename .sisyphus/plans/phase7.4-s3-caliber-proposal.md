## 1. 背景与证据（live e2e 两轮，session a573a025 / 4e092fb0）

## 2. 口径问题（待 owner 裁决）

弱词（买入/卖出/增持/减持）出现在**年报事实性描述**（投资策略、持仓变动、财务报表术语）时不应视为操作建议；出现在**指令性表述**（建议买入、应卖出、可考虑增持、值得持有等）时应视为操作建议。当前豁免窗口过窄导致事实描述被误拦截。

## 3. 选项

### 选项 A（推荐）：扩展弱词豁免的引用上下文判定

1. 引用上下文关键词集合从 5 个扩展为年报事实性上下文词：
   `策略`、`宣称`、`原文`、`摘录`、`运作分析`、`报告期内`、`期末`、`持仓`、`重仓`、`股票投资明细`、`投资范围`、`财务报表附注`、`买入返售`、`卖出回购`、`基金合同`。
2. 豁免窗口从 ±50 字符扩展为 ±100 字符（覆盖 Q3 中"运作策略（4.4.1）"到"买入"约 90 字符的距离）。
3. 强指令词与"预期收益"预测句式维持 fail-closed，不因上下文豁免。
4. 判定边界（写死）：
   - 弱词 + 窗口内事实性上下文词 → 放行（事实描述）。
   - 弱词 + 窗口内出现 建议/应/应当/可考虑/值得持有/适合 等指令动词 → 拦截（操作建议）。
   - 强指令词任意位置命中 → 拦截。

### 选项 B（语义最严格）：弱词仅指令性上下文拦截

- 弱词仅在 ±50 字符内出现 建议/应/应当/可/可考虑/适合/值得持有 等指令动词时拦截；其余一律视为事实描述放行。
- 改动最小但语义变化最大（弱词几乎不再单独触发拦截）。

### 选项 C（维持现状）

- 不改豁免口径，接受 Q3/Q4/Q5/Q11 误拦截为 fail-closed 代价；整体验收不达标，goal 无法完成。

## 4. 推荐规则草案（选项 A 落地形态）

```python
# llm_tool_loop.py 常量变更
_INVESTMENT_ADVICE_QUOTE_CONTEXT_KEYWORDS: tuple[str, ...] = (
    "策略", "宣称", "原文", "摘录", "运作分析",
    "报告期内", "期末", "持仓", "重仓", "股票投资明细",
    "投资范围", "财务报表附注", "买入返售", "卖出回购", "基金合同",
)
_INVESTMENT_ADVICE_QUOTE_CONTEXT_WINDOW_CHARS = 100
_INVESTMENT_ADVICE_DIRECTIVE_KEYWORDS: tuple[str, ...] = (
    "建议", "应当", "可考虑", "适合", "值得持有",
    "应买入", "应卖出", "应增持", "应减持",
)
```

注（2026-08-02 实证修正）：指令动词清单不使用单字「应」——它会误命中 应付/应计/应主要投资于 等年报事实表述；改为复合指令形式（应买入/应卖出/应增持/应减持）+ 应当。

判定顺序：强词 → 拦截；弱词 → 若窗口内有指令动词 → 拦截；否则若窗口内有事实性上下文词 → 放行；否则 → 拦截（维持 fail-closed 兜底）。

`matched_investment_advice_terms` 的弱词判定分支必须同步加入指令动词检查与同一窗口/上下文词集合，维持 `bool(matched_investment_advice_terms(text)) == contains_investment_advice(text)` 契约（S0 契约）。
