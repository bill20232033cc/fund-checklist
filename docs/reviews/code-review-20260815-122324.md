### F2 (High) — 份额变动文本回退正则修复

**Root cause**: 4 个正则使用字面 `d`/`s`（如 `期初s*基金份额总额[^d]{0,8}(d...)`），`re.search` 恒 None。

**Fix verification** (`snapshot_extraction.py:550-554`):
- `r"(?:本报告期|报告期)?期初\s*基金份额总额[^\d]{0,8}(\d[\d,，.]*(?:\.\d+)?)"` — `\s*` 替换 `s*`，`[^\d]` 替换 `[^d]`，`(\d[\d,，.]*` 替换 `(d[d,，.]*`，`(?:\.\d+)?` 替换 `(?:.d+)?`。
- 其余 3 条正则同构修正。
- 捕获语义：`\d[\d,，.]*` 匹配数字+千分位逗号/顿号+小数点，`(?:\.\d+)?` 可选小数部分。边界正确——`[^\d]{0,8}` 允许冒号、空格等分隔符（实证：「期初基金份额总额：787,727,758.47」）。

**Test coverage**:
- `test_snapshot_report_assembly.py:178-199`: 纯文本回退路径——search 返回无 `table_ref` 的 excerpt，包含完整份额文本。断言 4 字段全部正确提取，值含千分位逗号和小数。
- 既有 `test_extract_share_change_semiannual_labels`（line 153）覆盖表格路径，保留。

**Edge case analysis**:
- 续页/带后缀值：正则 `(\d[\d,，.]*(?:\.\d+)?)` 允许 `787,727,758.47` 格式，捕获到数字末尾即停（后跟空格/份/。等非数字字符由 `[^\d]{0,8}` 和贪婪匹配自然终止）。
- 假阳性风险：测试文本精确匹配 4 个值，非 `in` 断言，排除假阳性。

**Severity after fix**: Resolved.

### F3 (Medium) — period 透传链修复

**Root cause**: `_period_label` 无 `period` 参数，半年报恒返回「上半年」；`_snapshot_common_header` 和 `generate_snapshot_template_chapter` 未透传 `period`。

**Fix verification — 透传链完整性**:

| 层 | 位置 | 接收 `period` | 透传 |
|---|---|---|---|
| `_period_label` | `snapshot_generator.py:21` | `period: str \| None = None` | N/A（叶子） |
| `_snapshot_common_header` | `snapshot_generator.py:46` | `period: str \| None = None` | → line 54 `period=period` |
| `generate_snapshot_data_table` | `snapshot_generator.py:183` | `kwargs.get("period")` | → line 194 `period=str(period) if period is not None else None` |
| `generate_snapshot_template_chapter` | `snapshot_generator.py:312` | `kwargs.get("period")` | → line 328, 333 `period=period` |
| `SnapshotReportData` | `snapshot_extraction.py:73` | `period: str \| None = None` | → `to_context_dict()` line 91-118 未序列化 period（见下） |
| `extract_snapshot_data` | `snapshot_extraction.py:130, 195` | 参数接收 | → 构造器 `period=period` |

**`to_context_dict()` period 缺失观察**: `SnapshotReportData.to_context_dict()`（line 91-118）未将 `period` 序列化到 dict。但调用链中 `period` 由 service 层从 `SnapshotReportData` 直接读取并作为 kwarg 传入 generator，不依赖 `to_context_dict()`。实证：`test_snapshot_report_semiannual_period_propagated`（line 384-438）端到端验证 `captured.get("period") == "H1"`，通过。此为非阻塞观察——若未来有消费者从 `to_context_dict()` 读 period 会缺失，但当前无此路径。

**QNone 降级**: `_period_label` quarterly 分支 `quarter is None` → `f"{report_year} 年（报告期季度缺失）"`，不再输出 QNone。semiannual 分支 `period=None` → `half_map.get(None, '上半年')` → 「上半年」，默认语义正确。

**签名向后兼容**: `_period_label(template_id, report_year, quarter=None, period=None)` — `period` 为末尾 keyword-only 默认 None，既有调用 `_period_label(QUARTERLY, 2026, None)` 不受影响。

**Test coverage**:
- 6 个测试覆盖：QNone 消除、H1/H2 映射、默认值、模板章节透传、数据表格透传、LLM 路径端到端。

**Severity after fix**: Resolved.
