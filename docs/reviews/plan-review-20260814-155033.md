## Findings

### 001-未修复-高-测试计划正例「超额表现」路由断言错误

- **位置**: 测试计划 §1 正例
- **问题类型**: 测试缺口
- **当前写法**: `_route_plan_for_query("超额表现")` → `profile_name == performance_returns`
- **反例/失败场景**: 匹配机制 `any(alias in query ...)` 是子串包含。Proposed aliases = `("超额收益", "超额收益率", "超额", "净值表现")`。"超额表现" 不包含 "超额收益"、"超额收益率"、"超额"、"净值表现" 中任何一个 → `_route_plan_for_query("超额表现")` 返回 `profile_name=None`，测试断言失败。
- **为什么有问题**: 测试计划给了 implementation agent 一个错误的正例，会导致测试代码写错（断言 `performance_returns` 但实际返回 `None`），测试必然红，implementation agent 需要花时间定位是 plan 错误还是代码错误。
- **直接证据**: extraction.py:4755 `if any(alias in query for alias in contract.aliases)`；proposed aliases 不含可匹配 "超额表现" 的子串。
- **影响**: 实施 Agent 写出必红测试，浪费调试时间。
- **建议改法**: 从正例中删除 `("超额表现")`，替换为 `("超额收益")` 或 `("超额")` 等确实匹配 proposed alias 的 query。
- **修复风险**: 低
- **严重程度**: 高（测试计划错误直接阻塞实施）
